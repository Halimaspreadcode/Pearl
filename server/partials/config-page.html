Serveur d'envoi

Gmail refuse le mot de passe du compte — que saisir ?

Il faut un mot de passe d'application : 16 caractères, à générer sur myaccount.google.com → Sécurité → Mots de passe des applications. La validation en deux étapes doit être activée pour que l'option apparaisse. Google l'affiche par groupes de quatre — saisissez-le sans les espaces. Une erreur 535 BadCredentials au test signifie presque toujours que c'est le mot de passe du compte qui a été saisi.

Raccourci : renseigner SMTP_PASS (et au besoin SMTP_USER, SMTP_FROM) dans le fichier .env évite de ressaisir le secret ici après une réinstallation. Ce qui est saisi dans cette page reste prioritaire.

Envoi de test

Enregistre la configuration puis envoie un rapport à une seule adresse.

Alerte en cas d'échec

Un envoi programmé en échec est retenté 3 fois, toutes les 10 minutes. Si toutes les relances échouent, un mail part à cette adresse.

L'alerte passe par le même serveur d'envoi : s'il est en panne, elle échoue aussi. L'échec reste alors signalé dans l'application (Vue d'ensemble et cette page).
